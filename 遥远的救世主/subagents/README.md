# 《遥远的救世主》角色代理

按四步做成：

1. `roster.md` — 书中能核对的人
2. `quotes/` — 正向抽取（已知人名 + 动词 + 引号）。已修掉「上一句台词贴到下一个某某说」的错。脚本：`scripts/extract_dialogue.py`。卡里「核对台词」仍是手核。
3. 每人一张卡里的性格 + **文化属性**（豆豆：强势=循规律；弱势=指望救主、要强者破格给）
4. `*/SKILL.md` — 可直接塞进 subagent 的系统提示

## 怎么当 subagent 用

把对应 `SKILL.md` 全文作为子代理的 prompt 前缀，后面只加当前要办的事。例如：

```
你必须遵守下面这张角色卡，不得出戏。

<粘贴 丁元英/SKILL.md>

现在用丁元英的判断，回答：格律诗该不该庭外道歉。
```

在 Grok 里：`spawn_subagent`，`subagent_type=general-purpose`，prompt 如上。
