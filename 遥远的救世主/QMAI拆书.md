## 2. story：故事框架

### 框架 A　停手入局（第 1–8 章）

- **属于**：主线
- **开局钩子**：女刑警专程飞法兰克福，不是说情，是把一个男人从「一个人呆着」里捞回来。读者先见女人，再见账本。
- **铺垫**：私募基金 82% 利润时主动停。委托方用「商业道德」冻结资金。他只要 13.6 万零头吃饭。对韩楚风说出停手真相：取款机文化密码，屠杀不像打仗。
- **爽点**：不是赢钱，是赢了停的资格。文化属性四个字点题。
- **结尾钩子**：他去古城。女刑警会不会找到这个人。
- **一句话模板**：把一台正在出钱的机器关掉，因为破译者不愿再对同胞下屠刀；用「状态不佳」做法律外壳，用「一个人呆着」做心理外壳。
- **适用**：高人退隐开局、道德停手、把理念从酒桌带进生活。
- **作者留白**：基金清算的德文场面、韩楚风三桩酒、芮肖机场拥抱不够真诚。

### 框架 B　调查变成同居与课堂（第 9–22 章）

- **开局钩子**：刑警的职业雷达对准一个「不像闲人」的男人。
- **铺垫**：对诗、指定股票、给死囚画句号。她发现才气下面是判断。哑弹顶在头上之后她大哭：「怕死了以后见不到你。」
- **爽点**：文化属性三层（技术/制度/文化）被讲成可操作的审讯与产业逻辑。「精装歹徒」是爱称也是预警。
- **结尾钩子**：如果弱势文化就是等救主，他会不会给王庙村造一个神话。
- **一句话模板**：用一次差点死掉的职业事故，把师生关系焊成爱情；用爱情逼判断者把理论拿去实验。

### 框架 C　用音箱证伪价格神话（第 16–40 章）

- **开局钩子**：王庙村要神话。丁当众说：救世主是吃别人吃不了的苦，做出别人做不到的成本和质量。
- **铺垫**：欧阳雪真金 51% 控股，丁不入股。农户不进公司。欧洲测评当托儿。乐圣一次吃进 1000 套当「矛」。
- **爽点**：展会第二天批发 3400，一天卖空——两对套件的价值卖一对的价钱。乐圣旗舰滞销。
- **反爽**：600 万诉讼。叶冯刘瞒丁求和后退股。肖亚文在败诉窗口入主：诉讼是计划的一部分。
- **结尾钩子**：她被省厅借调。字条：「你送给我的礼物不是神话，是觉悟。」
- **一句话模板**：用边缘劳动做出可证伪的成本，砸开对手的价格神话；外战未开庭，自己人先按「打则皆死」退场。

### 框架 D　当死则死，救人者先走（第 41–46 章）

- **开局钩子**：遭遇战、哑弹的对照物变成真爆炸。
- **铺垫**：她毁容、残废，在增援到达前打心脏。组织「五不」：不烈士、不宣传、不抚恤、不记功、不开追悼会。同事怪他电话里沉默。
- **爽点（冷兑现）**：他只讲事实，不认为。摸她照片：「当生则生，当死则死，来去自如。丫头，不简单哪。」然后吐血。
- **结尾钩子**：刘冰跳楼，地上白纸。欧阳雪看见韩楚风的宝马来接大哥，不靠近。心里一句：大哥，你又要挨骂了。
- **一句话模板**：证明者先死；判断者按她的价值观沉默，被世人判为薄情；实验留下的公司继续咬人，他再次离开伤心之地。
- **作者留白**：电话 36 秒说了什么正文给了调查视角；遗产用信封套信封；内幕文件是否存在到最后仍是「不会那么简单」。

### 全书可复用结构记忆

```
破译者停手（不愿对同胞开取款机）
  → 用「一个人呆着」逃避
  → 被一个不怕死的人拖进爱与证明
  → 用音箱成本证伪价格神话（诉讼是计划）
  → 自己人按弱势文化退股；外来掌门接盘
  → 证明者按警察伦理赴死
  → 判断者按她的文化沉默，被骂薄情
  → 对手有枪不杀，选择坠崖保住自我评价
  → 弱者把白纸当成翻盘筹码，跳楼
  → 他等合作落地后离开，留下骂名
```

书名的用法：救世主是遥远的。王庙村等的不是神；芮小丹也不做他的神。谁期望破格获取，谁就在弱势文化里。

## 3. style：文风九维

抽样：1, 2, 3, 14, 15, 21, 41, 42, 46。与《天幕红尘》同宗，但本书课堂更长、情感收束更狠。

**narrativeDensity**
一场清算会、一场酒、一场审讯课后的卧谈，动辄数千字把因果讲完。死仍写快：第 42 章用通报体宣布自杀，再回丁的客厅。原则仍是：说理可慢，死必须手续化、然后疼。

**descriptionWeight**
景物功能性：选帝侯大街 vs 沉闷会议室；嘉禾园门口两辆车。芮自杀现场用伤情清单代替抒情。

**emotionRendering**
禁止五味杂陈。情绪走动作：划掉补偿条款、只要零头、擦印泥、整理茶具、吐一口鲜红的血。心理以判断/推演出现：「我只讲事实，不认为。」

**sentenceStyle**
叙述中长句，对白短硬可反驳。丁的德语/北京口语套逻辑；芮先刺后听。作者爱用法庭/会议纪要体插入（分红表、五不决定、伤情通报）。

**rhetoricDensity**
低。喻体日常：取款机、狼嘴里夹肉、句号、信封套信封、白纸。大词是「文化属性」「强势/弱势」「救主」。

**transitionStyle**
日期地点或序号小节点（章内 1/2）。不写时间空转。

**narrativeVoice**
第三人称多焦点。讲解权极大：基金条款、战法、诉讼、文化课。视角在芮、丁、欧阳、肖、韩之间切。

**dialogueStyle**
定义战。谁先定义「主」「文化」「道德」，谁掌控场面。芮的对白有刑警的直和女人的刺：「你怎么看谁都像贼啊」「精装歹徒」。

**thematicHabits**
高频点题，每次换操作域：停基金、审讯死囚、王庙村生产、自杀、跳楼。不怕重复「文化属性」。

### 附加

- **pointOfView**：第三人称多焦点 + 叙述者制度讲解权。
- **humorMechanisms**：一本正经拆台；「一夜风流」对「不适合男婚女嫁」。
- **highEnergyMechanisms**：把退路封死；兑现改用公文与伤情。
- **vocabularyPreferences**：文化属性、强势/弱势、救主、取款机、如是观、当生则生、判断、证明。
- **avoidPatterns**：把丁写成霸总救世主；把芮的自杀写成 Melodrama 哭戏；给王庙村一个致富神话的圆满；把韩楚风写成单纯金主。

### 风格宪法

1. 每场戏推进一个判断：这是强势文化还是等救主。
2. 开场用地点/会议/航班落地，禁止诗意空转。
3. 情绪走物件与手续：分红表、印泥、茶具、玉佩、白纸。
4. 说理必须落到一个可操作的例子（审讯、音箱、退股）。
5. 对白先抢定义权。
6. 死用通报体写完，再用一个活人的身体反应（吐血、不靠近送别）。
7. 主题词可重复，必须换域。
8. 收束不许组织追认英雄，不许复仇成功，只许离开与挨骂。
9. 女人不是符号：芮是证明者，欧阳是看着走的人，肖是把事办完的人。
10. 商业数字写清楚，因为数字就是判断的物证。

### 代表样本

**样本 1 · 停手（第 2 章）**

## 4. characters：角色 Skill

### 4.1 丁元英

**别名**：大哥　**首/末**：2 / 46

#### 01 公开资料
原《世界经济周刊》研究员，私募基金受托人，破译 A 股「取款机」密码。中等身材略瘦，德语流利。与韩楚风、郑建时因茶/佛相识。停手后来古城一个人呆着。格律诗与王庙村的总策划。不争正天总裁。

#### 02 对话方式
平静、先引条款再给判断。自嘲「江湖混子」「不是人话」。对芮可贫可硬。对警察：「我只讲事实，不认为。」
典型：
- 「本基金……不适合男婚女嫁。」
- 「再说，就不是人话了。」
- 「小丹有 6 年警龄，不用嘱咐。」
- 「当生则生，当死则死，来去自如。」

#### 03 表达特征
| 动作 | 心理 |
| --- | --- |
| 划掉补偿条款再签字 | 不卖声誉，也不欠人情 |
| 只要 13.6 万零头 | 把身价降到吃饭 |
| 整理茶具、放《天国的女儿》 | 用功课对抗崩盘 |
| 吐血、关灯伏床 | 理性尺度被身体推翻 |

#### 04 外部评价
格尔斯曼：掌握取款机文化密码。库兹曼：一夜风流。韩楚风：连你这江湖混子都下不去手了。芮：精装歹徒。同事王福田：为小丹感到不值。欧阳：大哥又要挨骂了。

#### 05 决策记录
1. 盈利时终止基金 → 冻结 + 禁业补偿被他划掉。技能：适可而止。
2. 教韩楚风不争总裁 → 让副总内耗，文化属性。
3. 给王明阳画句号 → 审讯打开。
4. 做格律诗/王庙村 → 实验强势文化，被写成剥削。
5. 电话 36 秒沉默 → 尊重她作为合格刑警，被判薄情。
6. 不告而别离开古城 → 伤心之地不再停留。

**失误**：群众工作与「证明」的公共翻译没做完（与叶子农同构）。对芮的沉默在他的文化里是礼，在同事的文化里是罪。

#### 06 时间线
早期：研究员 → 基金 → 停手。中期：古城、芮、课堂、公司。后期：芮死、诉讼、刘冰跳楼、夜路离开。

**成长弧**：不是变强，是从「反感而屈服着」被拖进证明，再被证明的代价打回「离开」。吐血是全书唯一一次他的尺度碎掉。

### 4.2 芮小丹

**别名**：小丹、丫头　**首/末**：1 / 42

#### 01 公开资料
古城刑警，省厅常抽调。警官大学与肖亚文相识。探亲在法兰克福。6 年警龄，一线少数女性。父亲芮伟峰。爱听《天国的女儿》。送丁「法」字玉佩。

#### 02 对话方式
先刺后听。「不用铺垫，直说。」「你疯啦？」能把丁的大词拽到「怎么用」。职业汇报极清楚。
典型：
- 「如果是有人托你给古城的什么案子说情，那就别说出来了。」
- 「倒是越看你越像个精装歹徒。」
- 「抱着我……我今天还是打死了一个人，这是第二个了。」

#### 03 表达特征
拥抱被肖说不够真诚。差点死后见丁会哭得像孩子。战场上能听黄福海喊「有种」。自杀选在增援接近时——把后续全部切断。

#### 04 外部评价
同事高评价。组织因自杀给「五不」。丁：不简单。肖：超然豁达的生死观。父亲不完全懂她的幸福。

#### 05 决策记录
1. 自费飞法兰克福堵肖办不成的事 → 把丁拉回人世。
2. 哑弹后仍做刑警 → 要丁帮她打开王明阳。
3. 参与/推动格律诗作为「实践与证明」。
4. 遭遇战后自杀 → 避免病房、慰问、负担与赞美。

**成长弧**：从「看谁都像贼」的职业防御，到用命给一种文化签字。她不是被丁洗脑，是自己选择当证明者。

---

### 4.3 欧阳雪 / 肖亚文 / 韩楚风 / 刘冰（简档）

**欧阳雪**：明珠饭店老板，丁的妹妹式自己人。格律诗董事长期间没见过「内幕文件」。芮死后不再轻易哭。终局停在小区路口，不靠近送别。功能：把大哥的离开翻译成「又要挨骂」。

**肖亚文**：精明干练，德语流利，基金时期的手。第 1 章就用路费绑架芮听完。后办诉讼、转告刘冰本可给股份。功能：把丁的意图办成手续。

**韩楚风**：正天总经理，酒桌上三桩问完。赌宝马一赔五。终局开 730 带保镖来接——大哥事先不让欧阳送。功能：兄长，也是「外面的世界」的车。

**刘冰**：本意不在打工。丁说过敏感期若无不当可给股份。跳楼，地上白纸。功能：弱势文化在公司内部的最后一跳——要一个破格的说法，没等到。

## 9. 仿写使用建议

- **项目灵魂**：判断优先、公文与课堂并置、死用手续写、疼用身体写。禁霸总，禁把扶贫写成神话圆满。
- **可借角色**：
  - 丁：当「停手的破译者」，不要当全知导师或救世主。
  - 芮：当「用命证明一种文化的人」，不要当被改造的小女人。
  - 欧阳：当「把离开翻译成挨骂的自己人」。
- **可借框架**：停手 → 被拖进证明 → 实验被误读 → 证明者死 → 判断者被骂着离开。
- **不可借**：原作人名、A 股基金细节、秦谷爆炸的原样复制。
- **与《天幕红尘》对照**：叶子农用命给「态度」签字；丁元英活着离开，签字的是芮小丹。一个被天幕绞死，一个把救世主推远，自己先走。
