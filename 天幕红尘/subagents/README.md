# 《天幕红尘》角色代理

四步：`roster.md` → `quotes/` → `文化属性对照.md` → `*/SKILL.md`

文化属性用本书自己的词：

- **见路不走**：实事求是，不住一法，走条件的可能
- **事于道**：把教条、经验、标签当路走（罗家明把四个字走成「做高人」）
- **态度**：叶子农用命签字的那一层
- **礼**：戴梦岩见白发说不出口；方迪选茶缸、给自己买墓

## 用法

把 `SKILL.md` 贴进 subagent prompt 前缀。

已成卡：叶子农、戴梦岩、方迪、老九、奥布莱恩、罗家明、林雪红、布兰迪、梁士乔、张志诚、沈彪、乔治。

评测：`对打题.md`。每张卡有时间切片和对打题。早段扮演禁止预知中弹。

`quotes/` 已重抽，章号是「第 N 章」，不再写成「回/章」。脚本：`scripts/extract_dialogue.py`。

与《遥远的救世主》对照：韩楚风、肖亚文在本书没有完整线；丁元英只在第 18 章被点到「丁」。不要串书补戏。
