## 2. story：故事框架

青幕要求只抽可复用结构，不复述原作人名。下面四段是本书实际节奏；每段后附「去人名模板」。

### 框架 A　死讯开场 → 债局登台（第 1–7 章）

- **属于**：主线
- **衔接**：无上一框。下一框：方案落地，隐士被迫入红尘。
- **开局钩子**：第一章就把「赢家」打死。读者不是问他能不能赢，是问：四个字怎么能逼死人？那个送字的人是谁？
- **铺垫**：债权人各怀体面，没人信那个柏林破屋能还债。女星用「时间以小时计」压场，隐士回敬「那你扛住地球」。规则先立：这不是求情戏，是判断戏。
- **爽点**：第二天他不谈责任，直接给方案。寡妇捂脸落泪——赌的不是钱，是「肯不肯负责、有没有能力」。女星从「没教养」改口「有种」。
- **结尾钩子**：调查此人。美国编导单独上门。四个字还没被真正解释。
- **一句话模板**：先打死一个误读理念的人，再让理念本人被孤儿寡母当稻草抓住，用超规格方案把体面债局改成利益共同体。
- **适用**：思想型长篇、商战开局、把「理念」从口号变成代价。
- **作者留白**：债局对白、女星与隐士第一次交锋的火气、破屋视觉。

### 框架 B　方案兑现 → 思想被商品化（第 8–17 章）

- **开局钩子**：方案开工。读者要看「蛇头」指控会不会坐实。
- **铺垫**：法律空档、官商双轨、地方保护、担保金结构——全是条件的可能，不是秘籍。编导把此人写成政论片理想作者：孤儿、将军之子、无家属牵连。
- **爽点**：豆子实验——任何立场都能从同一堆豆子里连出字母。隐士拒片：出了名就得交出自由。总裁顾问开始「看」这个人。
- **结尾钩子**：一张嘴就错。顾问没当回事，总裁却在意了。
- **一句话模板**：把一次游走法律边缘的成功，转化成外部权力对「新史观」的采购单；主角拒绝被采购，反而提高了自己的货值。
- **适用**：人才被猎头/媒体/情报系统盯上。

### 框架 C　政治套杀 → 态度兑现（第 18–44 章）

- **开局钩子**：顾问在酒会随口夸一句「难得的人才」。联盟半夜等在路边，要送一个他拒绝的部长头衔。
- **铺垫**：刑事传唤、机场挽臂、汉奸婆、元宵晚会砸车、巴黎软禁式保护。女星抓住他，经纪人说「攀不上」。他回国应讯不辩政治，只守法律。
- **爽点 / 反爽**：乔治命题战被「还没张嘴就错了」。顾问用 NRG 任命把他按进立场圈，他回国应讯、不回头。真正的枢纽是丝袜：《我的祖国》「关不得，放不得，撒手舍不得」——摘下保护，态度过关，狙杀的门也开了。台阶上中两枪：「还真他妈抬举我」「都是人的那点事」。
- **结尾钩子**：汉奸说不辩自明。女星要去质问白发老人。另一条线的女人在暴雨里瘫在桥上。
- **一句话模板**：对手不杀你的身体，先杀你的平静；把名誉做成无法洗清的公职，逼你用命给态度签字。
- **适用**：政治惊悚、名誉战、价值观殉道。

### 框架 D　后事与两个女人的收束（第 45–51 章）

- **开局钩子**：人已死，舆论翻转。商业价值回来了。
- **铺垫**：骨灰撒塞纳河。遗物、房子、笔记交国家。女星要见仇人；经纪人与面馆老板商量怎么不让她死。
- **爽点（冷兑现）**：女星见到满头白发，质问拿不起来，转身下楼——「该给这把年纪留点尊重」。登船前被面馆老板用「共同的表态」劝活，仍上船；船上无正文。另一女人不选国旗打火机，选大茶缸，给自己买 A9-22，碑上只红字「方迪」。
- **结尾钩子**：无下一轮剧情钩。主题钩：牵挂得有个寄托。墓是给飘荡的人躲雨的，也是把那个喜欢过他的自己埋进去。
- **一句话模板**：殉道之后不写复仇成功，写两个爱他的人各自用「礼」收场——一个把恨咽回去，一个把爱埋进去。
- **适用**：思想小说的人情尾声，避免英雄碑文。

### 全书可复用结构记忆

```
误读理念致死
  → 遗属用江湖方式绑架理念本人
  → 理念本人用条件的可能把债还上（义气入局）
  → 成功被外部权力翻译成「可采购的立场」
  → 主角拒绝被翻译
  → 对手改用名誉/公职/舆论完成政治谋杀
  → 主角用命给态度签字
  → 两个爱他的人分别用「尊重」和「寄托」收束，不复仇
```

作者手搓留白：见路不走的课堂（面馆、答辩、豆子、茶缸）、女星与隐士鸡同鸭讲的感情、打火机作为贯穿道具。

## 3. style：文风九维

抽样章：1, 5, 6, 8, 15, 16, 27, 40, 44, 49, 51。

### 3.1 九维画像

**narrativeDensity（叙事密度 / 节奏）**
信息不靠短句轰炸，靠「场面里把因果讲完」。一场债局、一场审讯、一场答辩，动辄数千字，中间几乎不切。快的地方是死：第一章从抽烟到开枪不到两千字；第四十四章从法国大餐到中弹，程序还没走完人就倒了。节奏原则：说理可慢，死必须快。

**descriptionWeight（环境描写）**
景物几乎总是功能性的。莫斯科空街、柏林贫民窟、红川秋色、塞纳河台阶、雨花亭秋陵——写完立刻回到人的动作或判断。连续抒情不超过三句。例外是方迪听死讯后的暴雨，那是把内心外化成天气，仍服务于「她必须离开会议室」。

**emotionRendering（情绪呈现）**
禁止「他感到五味杂陈」。情绪走动作：推袖、摸烟又放回去、领带扯到右下侧、打火机盖子自己开合、捂脸、跪在血泊里喊完立刻不喊。心理活动大量存在，但是以「判断 / 推演 / 自语」出现，不是抒情独白。

**sentenceStyle（句式）**
叙述句中长，逗号推进，爱用「……」和破折号收未说完的判断。对白极短、硬、可反驳。叶子农口吻是北京口语套逻辑：「咋」「嘛」「甭」「俺」「找抽」。作者叙述则偏书面，偶尔跳出来用「准确地说」「这时候」做法庭书记员式校准。

**rhetoricDensity（比喻密度）**
低。喻体日常：稻草当井绳、秃头上的虱子、带皮的玉米、镜像与豆子。几乎没有通感链。高密度修辞集中在主题词本身（见路不走、事于道、如来、场）。

**transitionStyle（过渡）**
日期 + 地点 + 天气，新闻导语式：「1991年8月24日夜，莫斯科。」「1992年8月12日，星期三，天气晴朗。」时空一刀切，不写「时间一分一秒过去」。

**narrativeVoice（叙述声音）**
第三人称有限全知。多数场面锁在在场者可知范围，但叙述者会插入制度史、法律条文、侨史、餐饮原理——这是作者的「讲解权」，不是角色的。视角常在叶子农、戴梦岩、方迪、老九、奥布莱恩、张志诚之间切换，一章一人或一场一人。

**dialogueStyle（对白）**
毛边口语 + 一竿子到底的定义战。谁先定义概念，谁就掌控这场。戴梦岩对白短、狠、要面子；老九直、土、认账；方迪清楚、会收、偶尔自嘲；奥布莱恩慢、冷、把人逼进选择题。潜台词极多，但作者会让另一个角色立刻点破，不玩「读者自己品」。

**thematicHabits（点题习惯）**
高频点题，且不怕重复。「见路不走」全书反复讲解：债局一次、红川对老九一次、面馆一次、答辩一次、巴黎一次。每次换一个操作域（投资 / 餐饮 / 论文 / 生死）。卷首议论、笔记摘录、临终句，是三次作者盖章。这不是网文「不点题」，这是思想小说的教学法。

### 3.2 附加字段

- **pointOfView**：第三人称多焦点限知 + 叙述者制度讲解权。
- **humorMechanisms**：一本正经拆台（「扛住地球」）；自贬式贫嘴（「打土豪分田地」）；土语砸在大词上（「找抽」）。
- **highEnergyMechanisms**：不靠热血加速，靠「把退路一条条封死」加压；兑现时突然改用极短动作句。
- **vocabularyPreferences**：见路不走、事于道、条件的可能、因果、场、众生、觉者、面子、担当、底线、礼、寄托；动词爱用「耗」「撬」「扛」「揣」「走」。
- **avoidPatterns**：心灵鸡汤收束；把见路不走写成励志鸡汤「做自己」；给叶子农加霸总光环；给奥布莱恩写成卡通反派；用大段景物抒情代替判断。

### 3.3 风格宪法（注入用硬约束）

1. 每场戏必须推进一个判断（人是什么、条件是否可能、谁在事于道），不为氛围写氛围。
2. 开章用「日期 + 地点 + 天气/场面」落地，禁止诗意空转过渡。
3. 情绪用动作和物件写：烟、袖子、领带、打火机、茶缸、血。禁止「他感到…」。
4. 说理场景允许长，但必须有物件实验或生活喻体（豆子、镜子、手擀面）把抽象钉死。
5. 对白先抢定义权。角色不互相抒情，互相拆概念。
6. 比喻每千字不超过 1–2 处，喻体必须是日常物。
7. 死、崩盘、中弹必须写快；活着的人收尾必须写慢、写礼。
8. 主题词可以重复，但每次必须换操作域，禁止同一解释复制粘贴。
9. 叙述者可以讲解制度/法律/商业原理，但讲解必须立刻回到在场人的利益。
10. 收束不许复仇成功，不许碑文式赞美，只许留下一个物件和一个未说完的态度。
11. 女人不写成附庸：一个用占有对抗虚无，一个用寄托对抗飘荡，两条线不要合并。
12. 反派不吼不笑，用程序、酒会、任命、舆论完成杀局。

### 3.4 代表样本（原文照抄）

**样本 1 · 死写得快（第 1 章）**
> 他将遗言放到电话上以免被血染红了，拿起枪对准太阳穴，随着一声枪响身体前倾倒伏在办公桌上，鲜血顺着办公桌的边沿往下流淌……

**样本 2 · 动作即性格（第 5 章）**
> 叶子农静静地听着，两手下意识地交替将两只袖子推上去很高，露出很长一截雪白的衬衣袖子，但他很快发现这种场合做这个动作有些匪气，又把袖子放了下来。接着他的手又下意识地伸进西服口袋去摸，摸出一盒香烟和一只打火机，刚拿出来就发现这个场合也是不适合抽烟的，于是也放了回去。

**样本 3 · 定义战（第 5 章）**
> 那不叫见路不走，那叫事于道，又走了一条见路不走的路。见路不走就是实事求是，不住一法，你理解成不拘经验教条就行了。

**样本 4 · 物件实验（第 15 章）**
> 而且不管你连出什么，都是真实的、有根据的。……这是个『场』的世界，有多少立场就有多少观点、主义。

**样本 5 · 临终（第 44 章）**
> 他又低头看了下胸前的血，说了句：「还真他妈抬举我。」身体就支撑不住了。……「都是人的那点事，没啥为什么。」然后微弱地念叨，「说你老土吧，你还不愿意。」

**样本 6 · 礼的收束（第 51 章）**
> 我们只见过一面，我没资格对你做什么……你要是不嫌弃呢，碰到刮风下雨就进来躲躲，累了就来歇歇脚，我把心放在这儿了。

## 4. characters：角色 Skill

### 4.1 叶子农（protagonist）

**别名**：子农、叶先生
**分类**：protagonist　**首/末**：5 / 44

#### 01 公开资料

- **人物定位**：全书判断中枢。退可反身修治，进可决战商场，对属人诱惑几乎免疫，对「态度」毫无免疫。
- **基础设定**：叶辉将军之子；父母文革中死于党内斗争；初中学历；黄埔政法大学、六祖佛学院各读两年退学；16 岁起研究马克思主义，至 1991 年约 22 年；英德双语为读原著；柏林诺伊瑟尔街破屋 + 16㎡店铺出租为生；不娶、不育、少社交。
- **能力**：看条件的可能；把法律空档、官商、侨网、地方政绩做成一次合法外观的劳务输出；把「实事求是」翻译成可操作口令「见路不走」。
- **阵营**：无党派。解释中国因果时被看成共产党，解释美国民主时又可被看成另一党。自己的说法：对错揣自己身上，不输出。

#### 02 对话方式

- **语气**：懒散、贫嘴、一竿子到底。先拆对方的定义，再给自己的定义。
- **用词**：咋、嘛、甭、俺、找抽、德行、抬举、事于道。
- **句式**：反问 + 归谬 + 生活喻体。很少命令人，但拒绝对方时毫不客气。
- **典型片段**：
  - 「那你就扛住地球让它走慢点，以天计算吧。」（5，对戴梦岩）
  - 「出了名就得交出自由，这个账我算得过来。」（15，对布兰迪）
  - 「还真他妈抬举我。」（44，中弹）
- **对话技能**：把大词从神坛拽到操作层；让对方承认自己在买立场，不是买真相。

#### 03 表达特征

| 表情/动作 | 心理 / 技能 |
| --- | --- |
| 西装里推袖、摸烟又塞回 | 市井习惯与场面礼仪打架，本质不装 |
| 领带扯到右下侧、袖子撸高 | 一进入推理就忘记风度 |
| 打火机盖子「自己」开合 | 手癖；后来成为政治态度的载体（国旗机） |
| 破屋待客、车却极干净 | 「出了门就是公共规则」 |
| 大茶缸泡茉莉花茶 | 孤独、念文革夏夜扎堆聊天 |
| 中弹先看血再骂抬举 | 把谋杀还原成「人的那点事」 |

#### 04 外部评价

- 林雪红：走火入魔的四个字；又是唯一稻草。
- 戴梦岩：先「没教养」「脑子不正常」，后「有种」；梁士乔评「按你的标准他攀不上你，按他的标准你攀不上他」。
- 老九：仗义；嘴难撬；「见路不走，真好哇」。
- 布兰迪：「你是我见过的最有头脑的傻瓜。」
- 张志诚：「子农属豹子的，吃独食惯了，做群众工作他还需要学习。」
- 旁白：除了乌合之众的伤害，几乎对属人诱惑免疫——但这是外部神话，正文其实写他怕给戴梦岩惹记者。

#### 05 决策记录

**风格**：主导、理性、认因果。一旦认了义，就不修改条件来偷生。

1. **柏林受责**  
   背景：萍水之交被寡妇当责任主体。备选：扔小钱打发 / 讲理推脱 / 接。决策：接，用劳务输出。结果：债还了，平静毁了。技能：条件的可能。
2. **拒政论片**  
   背景：高酬、舞台、一夜成名。决策：拒，因为要交自由，且片子是给「场」供货。结果：被标记为更有价值的猎物。
3. **回国应讯 + 拒部长**  
   背景：刑事传唤与部长任命前后脚。决策：回国，只谈法律不谈政治。结果：汉奸帽子扣到戴梦岩头上。
4. **巴黎出门**  
   背景：戴梦岩用保护否定了他的态度。备选：继续躲 / 出门。决策：出门吃一顿订了十天的法国餐。结果：被狙杀。他自己说：改任意一个前条件都能活，他这种德行就不会改。

**失误**：张志诚评「事情没搞扎实就跑出来了」——群众工作、伴侣心理支持都没做完。他承认「想避免麻烦，可以不见布兰迪……」，智力够，选择不够活。

#### 06 时间线

- 早期：买 5 分钟 → 温州验证 → 还 50 万 → 送四个字 → 去柏林研究。
- 中期：受责 → 布达佩斯/红川操作 → 教老九做面 → 拒片子 → 纽约见乔治。
- 后期：NRG 部长事件 → 回国受审 → 与戴梦岩公开关系 → 巴黎保护 → 出门被杀。
- 转折点：第五章说「我会尽力」的那一刻，隐士身份结束。

**成长弧**：不是变强，是被自己的义气从「看客」拖进「当事人」，再被自己的态度从「当事人」拖进「祭品」。

**代表性台词**

- 「见路不走就是实事求是，不住一法。」
- 「我是野生植物，一弄成盆景就不知道该怎么活了。」
- 「先拿钱是必然，后拿钱是碰运气。」
- 「这个人只要一不是老百姓，就算完了。」（奥布莱恩对其判断）
- 「不找死，不找活，平常过日子。」
- 「都是人的那点事，没啥为什么。」

### 4.2 戴梦岩（protagonist）

**别名**：梦岩、梦姐　**分类**：protagonist　**首/末**：2 / 50

#### 01 公开资料

香港当红影星，片酬与票房头部，港、巴黎有房产；恩师苏玉平；最大私人债权人（本息 36 万美金）。第 13 章柏林表白，第 27 章机场挽臂宣示，但她后来说「我是人，他是猫」「没有可能」——不是恋人闭环，是占有与共签态度。公民身份隶属港英，这成为她后半段心理崩溃的法理缺口。买 20 万港币纯金盔甲火机（第 12 章）；用 260 万港币商标合同换法国签证通道。

#### 02 对话方式

短、硬、要面子，先下判断再补理由。被刺痛时立刻人身：「没教养」「脑子不正常」。认账时也只给两个字：「有种。」对老九改称「九哥」，对梁士乔始终是利益共同体式的坦白。

典型：
- 「还有什么事能比颁奖典礼更重要？」
- 「那我们这些人不就都成蛇头了吗？」
- 「我质问一声可以吗？喊一下疼可以吗？」
- 「他满头白发，一我说不出口了。……该给他这把年纪留点尊重。」

#### 03 表达特征

戏里吊威亚双手持枪；戏外累到要人架着仍伸手指梁士乔。机场当众挽臂是宣示占有。中弹现场先歇斯底里，听到「人的那点事」立刻沉默——她能从表演态切回判断态，但切得疼。

#### 04 外部评价

梁士乔：不是爱，是占有；攀不上。媒体：汉奸婆 → 毒妇镀金 → 义士遗孀。老九：你做得不是好不好，是对。张志诚：宁折不弯；缺关系权利的心理支持；无愧祖国。

#### 05 决策记录

1. 改道纽约悼念/查债：典礼让步于第一时间反应。
2. 债局垫资但要先查人：商人理性。
3. 日本餐馆后改「接触」为「抓住」：女人的考虑压过经纪人的利益。
4. 巴黎保护 vs 放他出门：她最终让态度过关，等于共同签字。
5. 见奥布莱恩又不说：恨被「礼」按住。

**成长弧**：从身价细节论到能演宋庆龄的成熟，再被舆论与丧痛压回「活一天是一天」。她没有完成自我和解，船是释放阀。

### 4.3 方迪（protagonist）

**别名**：方总　**分类**：protagonist　**首/末**：9 / 51

#### 01 公开资料

军八大院，爷爷中将、父亲少将、哥哥从军。纽约圣尼耶尔新闻硕士 + 在读 MBA。会采编、会跳舞、会抽烟喝酒赶稿。后任老九北京「久悟杠子面」操盘。与叶子农只见一面。

#### 02 对话方式

清楚、会收、先自嘲再进逼。对老九称九哥，敢说「我还知不知道自己是谁了」。对张志诚不装懂政治，但能把戴梦岩的死活翻译成国家话语。答辩时能把故意混淆的提问拆回定义。

#### 03 表达特征

镜子里孤芳自赏；暴雨中瘫在桥上分不清雨和泪；扫墓时不哭，雕塑般平静，眼泪却决堤。选茶缸不选国旗机——她碰得动孤独，拿不动政治象征。

#### 04 外部评价

张志诚：仗着方将军影响搞调查，胆大。方父：只见一次不能刻意拔高。赵经理：方总真是人才。她自己：今天我才像个战士，硕士比战士差远了。

#### 05 决策记录

1. 接调查单：当新闻活干，一夜出中英报告。
2. 拒「看」方案，改实习：知道自己不是审稿人。
3. 论文《决策的法则—见路不走》：把理念从神道收成管理法则。
4. 替老九传话给张志诚：明知介入政治，仍去。
5. 买墓、放录像带和不锈钢打火机：把没资格的爱做成寄托。

**与戴梦岩的结构差**：戴是占有线，方是旁观-内化线。两人无交集。拆书时不要写成「两个女主抢一个男主」。方迪自己承认：爱上他，「从那天我给他们当公证翻译。」墓碑只刻「方迪」——埋的是那个喜欢过他的自己，也是给他一个躲雨处。

### 4.4 老九 / 慕容久（supporting）

纽约「老九面王」老板，40 岁，高大黝黑，西装里透土气。债是房主抵过来的，与罗家明本不相识。说话直：「还要脸不要了？」被叶子农教过一个月，把见路不走做成消灭厨师依赖的连锁面。送酱、送面、送人。能掉泪，爹走都没掉。决策风格：认账、扛事、怕办砸所以找方迪补政治弦。

台词：「人家都见路不走了，我还不知道路在哪儿呢。」「你做得不是好不好，是对。」

---

### 4.5 奥布莱恩（antagonist）

迪拉诺总裁顾问，退休前中情局情报分析专家。雪白头发，驼背消瘦。手法：不直接下手，让酒会闲聊变成公职任命，让舆论完成教训。戴梦岩说「操纵这一切的竟是远在纽约的一只老人的手」。他要的不是叶子农加入，是让叶子农的平静不可能。终局：女人来质问，他迎出来；女人看见这把年纪，说不出口。反派不被打脸，被「礼」赦免——这是本书最冷的收束。

---

### 4.6 罗家明（supporting，功能：误读样本）

温州商人，权力经济玩家。1987 年用 2000 块买 5 分钟，再砸 5 万，收回 50 万却只要四个字。把见路不走听成「跟别人不一样 / 做高人」。苏联局他判断不了，资金也撑不住，却放大愿意放大的。遗书两句：「我撑不住了。我不能请求原谅，这不是可以原谅的事。」全书第一具尸体，也是理念的第一面镜子：四个字本身不杀人，事于道才杀。

---

### 4.7 林雪红 / 布兰迪 / 梁士乔 / 张志诚（简档）

**林雪红**：乱局里唯一清醒的遗孀。传真条理清楚，梁士乔一眼看出她关心的是债。柏林突袭、头等舱五星级、把侨会变成道义场。赌赢了「肯负责」，也把隐士拖进红尘。

**布兰迪**：美国式编导。休假可去柏林，理由要充分。出调查费。豆子实验后仍想握手。功能：把叶子农从江湖义气翻译成可立项的国际话语，打通奥布莱恩。

**梁士乔**：细节论经纪人。第一次改行程不悦，但永远把场面收拾干净。看穿林雪红文笔；按住戴梦岩的火；后事不扩大范围。利益在她身上，底线也在她身上。

**张志诚**：国安办公室主任。急茬急办但不先弄动静。收笔记、给方迪留茶缸、给戴梦岩解负罪感、批评叶子农群众工作。他是国家视角的叙述出口。

## 9. 仿写使用建议（青幕灵魂库）

- **项目灵魂**：克制、判断优先、口语说理、死写快、礼写慢。禁鸡汤，禁霸总，禁双女主合体。
- **可借角色**：
  - 叶子农：当「拒绝被立场采购的判断者」，不要当全知导师。
  - 戴梦岩：当「用占有对抗虚无的成名女人」，保留她的商人理性。
  - 方迪：当「把理念做成事业、把爱做成礼的旁观者」，不要写成备胎。
  - 奥布莱恩：当「用程序杀人的老人」，不要写成地下党反派。
- **可借框架**：误读 → 义气入局 → 被采购 → 用命签字 → 礼的收束。
- **不可借**：原作人名、苏联/NRG 具体情节、打火机国旗梗的原样复制。
