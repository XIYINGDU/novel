# 《红楼梦》角色代理

四步：`roster.md` → `quotes/` → `文化属性对照.md` → `*/SKILL.md`

红楼的「文化属性」不用硬套豆豆原词，改成书里自己的尺子：

- **情**：意淫、木石、真性
- **礼**：仕途经济、体统、金玉
- **权**：协理、放账、弄权
- **了**：好了、出世、斩情

豆豆的弱势（要破格、要别人做主）仍能对上：贾赦逼鸳鸯、贾瑞照风月鉴、薛蟠准折迎春。

## 用法

把 `SKILL.md` 贴进 subagent prompt 前缀，后写要办的事。

已成卡：贾宝玉、林黛玉、薛宝钗、王熙凤、贾探春、贾母、花袭人、晴雯、刘姥姥、贾政、史湘云、鸳鸯、甄士隐、贾雨村。

评测：`对打题.md`。每张卡有时间切片和对打题。前 80 扮演禁止用续书结局。

`quotes/` 已重抽：人名必须在已知表里，动词最长匹配（「笑道」不会拆成「宝玉笑」）。章回号含「第一○○回」这类○。脚本：`scripts/extract_dialogue.py`。
